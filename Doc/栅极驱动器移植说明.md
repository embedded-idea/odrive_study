# 栅极驱动器移植说明（EG2134 / DRV8301 切换）

> 配套文档：`Doc/ODrive移植说明v0.5.6.pdf`（下称"移植手册"）。
> 手册第 6 节记录的是早期"用 FD6288 手工替换 DRV8301"的操作流程；当前仓库已把该流程收敛为**编译期宏切换**，本文档描述代码现状，与手册配合阅读。

## 1. 速查

| 硬件 | 编译方式 | 默认 |
| --- | --- | --- |
| EG2134 三相栅极驱动 | `make`（不加任何宏） | ✅ 默认 |
| DRV8301（原厂硬件） | Makefile `C_DEFS` 加 `-DGATE_DRIVER_DRV8301` | |

切换开关是编译宏 **`GATE_DRIVER_DRV8301`**：不定义 = EG2134，定义 = DRV8301。

## 2. 切换机制在哪里

**① `Board/v3/Inc/board.h`（约 95~118 行）—— 类型层**

```cpp
#if defined(GATE_DRIVER_DRV8301)
#include <Drivers/DRV8301/drv8301.hpp>
#else
#include <Drivers/EG2134/eg2134.hpp>
#endif

#if defined(GATE_DRIVER_DRV8301)
using TGateDriver = Drv8301;
using TOpAmp      = Drv8301;
#else
using TGateDriver = Eg2134;
using TOpAmp      = Eg2134;
#endif
```

`MotorControl/` 下的控制逻辑（`motor.hpp` 等）**只通过 `TGateDriver`/`TOpAmp` 两个别名访问驱动器**，因此切换硬件不需要改动任何控制代码。

**② `Board/v3/board.cpp` —— 实例化与板级差异**（见下节）

**③ `Makefile` 的 `C_DEFS`（约 205~209 行）**：目前没有定义 `GATE_DRIVER_DRV8301`，所以默认编译产物为 EG2134 版本。

## 3. 两颗芯片的硬件差异与代码对应

| 差异点 | DRV8301 | EG2134 | 代码位置 |
| --- | --- | --- | --- |
| SPI 配置接口 | 有（寄存器/增益可编程） | 无 | `board.h` include 分支 |
| 使能/复位 | EN_GATE 拉低 40µs → 拉高 20ms 复位时序 | 无，上电即工作 | `board.cpp` L396 |
| 故障检测 | nFAULT 引脚 | 可选：外部过流比较器接 `fault_gpio` | `Eg2134(fault_gpio)` 构造参数、`do_checks()` |
| OTP 版本校验 | 必须通过，否则卡死 | 跳过（定制板通常没烧 OTP） | `board.cpp` L296 |
| 状态指示 | — | PD2（原 nFAULT 脚）作状态 LED，TIM8 中断里每 0.5s 翻转 | `board.cpp` L311 / L514 |
| 电流采样运放 | 芯片内置可编程增益 | 外部固定增益电路（20 倍，见手册第 5 节） | `Eg2134::config()` |

## 4. 切换回 DRV8301 硬件的步骤

编辑 `Makefile`，在 `C_DEFS` 末尾加一行：

```makefile
C_DEFS =  \
-DSTM32F405xx \
-DHW_VERSION_MAJOR=3 \
-DHW_VERSION_MINOR=6 \
-DHW_VERSION_VOLTAGE=56 \
-DGATE_DRIVER_DRV8301
```

然后重新编译：

```bash
make clean && make -j$(nproc)
```

## 5. 新增第三种栅极驱动芯片（三步）

1. **新建驱动类**：在 `Drivers/<芯片名>/` 下实现一个类，同时继承 `GateDriverBase` 和 `OpAmpBase`，方法集参照 `Drivers/EG2134/eg2134.hpp`：
   - `config(requested_gain, *actual_gain)` —— 返回实际运放增益
   - `init()` / `is_ready()` / `do_checks()` / `get_error()` —— 初始化、就绪状态、故障轮询
   - `get_midpoint()` / `get_max_output_swing()` —— 运放中点与摆幅
   - ⚠️ `is_ready()` 在 `init()` 之前必须返回 `false`：`board.cpp` 用它作为"电流采样是否有效"的门控，否则上电阶段会误报 `ERROR_CURRENT_SENSE_SATURATION`
2. **`Board/v3/Inc/board.h`**：加一个 `#if defined(GATE_DRIVER_XXX)` 分支（include + 两个别名）
3. **`Board/v3/board.cpp`**：在 `m0_gate_driver`/`m1_gate_driver` 构造处加分支，并按需补充板级差异的 `#if`（复位时序、LED、OTP 校验等）
